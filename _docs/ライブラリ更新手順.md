# ライブラリ更新手順

最終更新: 2026-03-08

## 対象

Markdown 表示用にアプリへ同梱している以下のライブラリ。

- `marked`
- `DOMPurify`
- `PrismJS`
- `@mermaid-js/tiny`
- `github-markdown-css`

配置先:

- `MarkdownViewer/Assets/vendor/`

## 基本方針

- CDN は使わず、必要ファイルをプロジェクトへ同梱する。
- 更新時はバージョンを固定して取得する。
- 取得後は `THIRD-PARTY-NOTICES.md` と LICENSE 同梱内容を更新する。

## 取得方法

一時ディレクトリで `npm` を使って取得する。

```bash
rm -rf /tmp/markdownviewer-assets
mkdir -p /tmp/markdownviewer-assets
cd /tmp/markdownviewer-assets
npm init -y
npm install marked@16.2.0 dompurify@3.2.6 prismjs@1.30.0 @mermaid-js/tiny@11.10.0 github-markdown-css@5.8.1
```

バージョン番号は更新対象に合わせて置き換える。

## 更新対象ファイル

以下の一覧を正とし、必要ファイルの不足や余計なファイル混入がないことを確認する。

### marked

- 取得元: `node_modules/marked/lib/marked.umd.js`
- 配置先: `MarkdownViewer/Assets/vendor/marked/marked.umd.js`
- LICENSE: `node_modules/marked/LICENSE.md`

### PrismJS

- 取得元:
  - `node_modules/prismjs/prism.js`
  - `node_modules/prismjs/components/prism-csharp.min.js`
  - `node_modules/prismjs/components/prism-typescript.min.js`
  - `node_modules/prismjs/components/prism-json.min.js`
  - `node_modules/prismjs/plugins/line-numbers/prism-line-numbers.min.js`
  - `node_modules/prismjs/plugins/line-numbers/prism-line-numbers.min.css`
  - `node_modules/prismjs/themes/prism-okaidia.min.css`
- 配置先: `MarkdownViewer/Assets/vendor/prism/...`
- LICENSE: `node_modules/prismjs/LICENSE`

補足:

- 対応言語を増やす場合は `components/` から必要な `prism-*.min.js` を追加する。

### DOMPurify

- 取得元: `node_modules/dompurify/dist/purify.min.js`
- 配置先: `MarkdownViewer/Assets/vendor/dompurify.min.js`
- LICENSE: `node_modules/dompurify/LICENSE`

補足:

- ライセンスは `Apache-2.0 OR MPL-2.0`。
- 更新時は `THIRD-PARTY-NOTICES.md` のライセンス表記も合わせて更新する。

### @mermaid-js/tiny

- 取得元: `node_modules/@mermaid-js/tiny/dist/mermaid.tiny.js`
- 配置先: `MarkdownViewer/Assets/vendor/mermaid/mermaid.tiny.js`
- LICENSE: `node_modules/@mermaid-js/tiny/LICENSE`

### github-markdown-css

- 取得元: `node_modules/github-markdown-css/github-markdown.css`
- 配置先: `MarkdownViewer/Assets/vendor/github-markdown-css/github-markdown.css`
- LICENSE: `node_modules/github-markdown-css/license`

## 更新後に確認するファイル

### 1. アセット本体

- `MarkdownViewer/Assets/vendor/...`

### 2. 同梱一覧

- `THIRD-PARTY-NOTICES.md`

更新内容:

- ライブラリ名
- バージョン
- ライセンス
- 配置先
- 取得元

### 3. 読み込みコード

- `MarkdownViewer/MainWindow.xaml.cs`

確認内容:

- 参照パスが `Assets/vendor/...` と一致していること
- 新しいファイル名に変更がある場合は反映されていること

## 動作確認

最低限、以下を確認する。

1. 通常の Markdown が表示できる
2. コードブロックのシンタックスハイライトが動く
3. `mermaid` コードブロックが描画される
4. HTML テーブルなど、必要な生 HTML が表示できる
5. `Unsafe` トグル OFF で危険な HTML が除去される
6. `Unsafe` トグル ON でそのセッション中だけサニタイズを無効化できる
7. 相対画像が表示される
8. オフライン状態でも表示できる

## ライセンス確認

更新時は以下を確認する。

1. `package.json` の `license`
2. 同梱した LICENSE ファイル本文
3. `THIRD-PARTY-NOTICES.md` の記載内容

`MIT` 以外のライセンスへ変わっていた場合は、配布条件の確認を先に行う。
